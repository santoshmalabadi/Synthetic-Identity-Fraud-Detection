# Synthetic Identity Fraud Detection

**AI-powered synthetic identity fraud detection platform for digital banking.**

---

## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- pip

### Installation

```bash
# Clone or extract the project
cd synthetic_identity_fraud_detection

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

The application opens at **http://localhost:8501**

---

## 📋 Usage Guide

### Step-by-Step Demo Flow

1. **Generate Synthetic Data** ← Start here  
   - Set applicant counts (default: 60 normal, 20 synthetic, 15 fraud-ring, 5 new)  
   - Click "Generate & Save Dataset"  

2. **Risk Analysis** → "Re-score All Applicants"  
   - Runs the explainable rule-based scoring engine  
   - Populates shared-attribute flags and risk categories  

3. **Relationship Graph**  
   - Visualise applicant connections through shared attributes  
   - Click an applicant to highlight connections  

4. **Fraud Ring Detection** → "Detect Fraud Rings Now"  
   - Discovers connected suspicious groups via NetworkX  
   - Explore individual rings with subgraph visualisation  

5. **Investigation Centre**  
   - Review suspicious cases  
   - Mark as "Confirmed Fraud", "Cleared", or "Under Review"  

6. **Performance Evaluation**  
   - Compare detection accuracy against hidden ground-truth labels  
   - Adjust threshold slider to see precision/recall tradeoffs  

### Demo Scenarios (no manual data entry needed)

| # | Scenario | Location |
|---|----------|----------|
| 1 | Synthetic Identity Combination | Generate Data → Scenario 1 |
| 2 | Fraud Ring – Reused Attributes | Generate Data → Scenario 2 |
| 3 | Genuine Family Members | Generate Data → Scenario 3 |
| 4 | New Identity Assessment | Generate Data → Scenario 4 |

## ⚠️ Important Notes

- All data is **100% synthetic** — generated by Faker, never real personal information
- The system **never automatically rejects** applicants — it recommends human review
- Shared attributes alone are **not proof of fraud**
- Performance metrics are from synthetic test data only

## 🛠️ Troubleshooting

| Issue | Fix |
|-------|-----|
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` |
| Empty dashboard | Go to "Generate Synthetic Data" first |
| Zero risk scores | Go to "Risk Analysis" → "Re-score All" |
| Graph is empty | Re-generate a larger dataset (≥50 applicants) |
| DB errors | Delete `data/database/fraud_detection.db` and restart |
